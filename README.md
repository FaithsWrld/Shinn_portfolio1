# Shinn Portfolio

A responsive, single-page portfolio for Faith Kola-Olusa (Shinn), built with plain HTML, CSS and JavaScript. No build step or package installation is required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. The page uses Google Fonts when online and includes system-font fallbacks.

## Deploy

This repository is ready for GitHub Pages: open **Settings → Pages**, choose the `main` branch and `/ (root)` as the source, then save.

## Contents

- `index.html` — portfolio content and project links
- `css/site.css` — responsive layout, visual design and reduced-motion support
- `js/site.js` — current-year footer
